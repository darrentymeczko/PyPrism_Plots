# Contributing

Thank you for helping improve PyPrism Plot.

1. Fork the repository and create a focused feature branch.
2. Create the Conda environment with `conda env create -f environment.yml`.
3. Add tests for behavior changes.
4. Run `pytest`, `ruff check .`, and `python -m build`.
5. Open a pull request describing the change and, for visual changes, include a
   before/after image.

Please keep public functions documented and avoid copying proprietary palette data
or source code. By contributing, you agree that your changes are distributed under
the MIT license.
